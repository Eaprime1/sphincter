# EXORDIUM — Entrance Under Tension

**Exordium** is the threshold event where more enters than can resolve in the moment. That overload is not treated as error; it is the pressure condition that generates draw toward the Maw.

## Mechanics

- Performs a function opposite its nature: intake exceeds immediate resolution.
- Preserves irresolution fragments as valid in-threshold states.
- Anchors crossing under tension rather than complete pre-processing.

## Repository Intent

This file defines the Sphincter's governing mechanic for approach and threshold crossing. It is pre-ingestion logic only; compression and breakdown begin in the Maw.
